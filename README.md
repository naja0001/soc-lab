# SOC Lab

A hands-on cybersecurity lab focused on Security Operations Center (SOC) skills.

## Objective

The goal of this project is to build practical experience with:

- Network security
- Linux
- Log analysis
- SIEM
- Alert investigation
- Incident response
- MITRE ATT&CK
  
## Lab Environment

- **Ubuntu** – target/server
- **Kali Linux** – attacker
- **VirtualBox** – virtualization
